# BOIPEBA: Além do Postal

Site do projeto **Boipeba: Além do Postal** — histórias da Ilha de Boipeba (Cairu, BA) acessadas por QR Codes em cartões-postais.

Design Disruptivo · Prof. Tabatha · Senac 2026
Aline Pinheiro · Henrique Mendelini · Pedro Moura

## Onde editar

- `js/historias.js` — textos, fotos e dados de cada postal (e a linha do tempo)
- `js/equipe.js` — página "Sobre nós"
- `css/style.css` — identidade visual (cores, fontes, layout)
- `img/` — fotos · `img/selos/` — selos gráficos · `img/equipe/` — fotos do grupo
